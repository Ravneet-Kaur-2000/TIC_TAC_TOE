## About The Project

* This JavaScript-based Tic Tac Toe game allows two players to alternately place "X" or "0" in a 3x3 grid. The game starts with Player 1 placing "X," followed by Player 2 placing "0." 
* The game checks for a winner after each turn by evaluating all possible winning combinations. If a player wins, a message is displayed, and the winning cells are highlighted. 
* If all cells are filled without a winner, the game declares a tie. A reset button allows players to restart the game. 
* The game's state and logic are managed entirely through JavaScript functions.
